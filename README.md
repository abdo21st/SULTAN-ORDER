# نظام إدارة طلبات حلويات السلطان (SOMS)

نظام ويب متكامل (Full-Stack) لإدارة وتتبع دورة حياة طلبات الحلويات، يعتمد على السحابة (Cloud-Based) لضمان الوصول من أي مكان.

## 🚀 المميزات الجديدة (2.0)

- **قاعدة بيانات سحابية**: الاعتماد على MongoDB Atlas لحفظ البيانات بشكل دائم وتزامنها بين جميع الفروع.
- **إدارة كاملة**: إضافة وتعديل المستخدمين والفروع مباشرة من داخل التطبيق.
- **دعم فني**: أداة نشر تلقائي لتسهيل التحديثات.

## 📂 المجلدات الرئيسية

- `app/`: الكود المصدري (Frontend & Backend).
- `docs/`: التوثيق والملفات الأرشيفية.
- `public/`: الصور والملفات الثابتة.

## 🚀 كيفية التشغيل محليًا

1. ثبّت الاعتماديات باستخدام `npm ci`.
2. أنشئ ملف `.env.local` في جذر المشروع وأضف فيه `MONGODB_URI` بقيمة رابط الاتصال بقاعدة MongoDB المخصصة للتطوير.
3. شغّل `npm run dev` وافتح [http://localhost:3000](http://localhost:3000).

استخدم `npm run lint` لفحص الكود و`npm run build` لإنشاء نسخة الإنتاج.

## النشر

يتوفر [deploy_update.bat](deploy_update.bat) في جذر المستودع. عند تشغيله على Windows من جذر المشروع، يضيف كل تغييرات ملفات العمل إلى Git، ويسجّلها في التزام، ويدفع الفرع الحالي إلى GitHub.
